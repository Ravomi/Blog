欢迎来到 **Waya's Bakery**。

把新博客部署在 `waya.ink` 的时候，我想起街角那些早上七点就开始揉面团的小面包店：推门进去没有复杂的菜单，只有刚出炉时麦香和黄油混在一起的踏实感。这也是我希望这个小站呈现出来的样子。

## 为什么要分开 Blog 和 Notes

以前写博客最大的心理负担，往往是“觉得还没攒够一篇大文章”。很多有意思的工程发现、调试踩坑或者一闪而过的念头，因为不够长，最后都散落在聊天记录或草稿箱里不见了。

所以这里分成了两块：

- **[Notes](/notes/)**：放几句话就能说清的日常思考、工具折腾与碎碎念，没有标题压力，随写随发；
- **[Blog](/posts/)**：放经过沉淀、结构完整的长文复盘与技术笔记。

## 极简与耐看的技术栈

整个站点完全基于静态生成（Hugo + 原生 CSS/JS），不引入繁重的前端运行时框架：

```bash
# 本地实时预览
hugo server -D

# 新写一条碎碎念或文章后，直接推送即可自动部署
git add .
git commit -m "new loaf"
git push
```

好处非常直接：

1. **快且纯粹**：首屏只有干净的 HTML 与几百行样式，阅读时没有任何干扰；
2. **数据自在**：所有内容都在 `content/` 目录下，是干干净净的 Markdown 纯文本；
3. **随手检索**：按 `/` 即可唤起全站搜索，在 `/notes/` 里也能按分类、年份或喜欢数快速筛选。
