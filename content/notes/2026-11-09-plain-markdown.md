越用越多工具之后，最后留下来的反而全是最朴素的纯文本和命令行。只要底层还是一个个干净的 `.md` 文件和 Git 仓库，不管是自己用编辑器改，还是让 Agent 帮忙整理归档，都顺滑得没有任何阻力。
<!--more-->

以前总容易掉进“配置笔记系统”的陷阱里：纠结双向链接、插件生态、私有同步协议。后来发现真正决定输出质量的，从来不是容器有多花哨，而是从“冒出一个念头”到“落成一行字”之间的摩擦力有多小。

现在的原则很简单：

- 数据永远是本地可读的纯 Markdown；
- 构建工具足够快，毫秒级生成静态 HTML；
- 十年之后打开，依然不依赖任何闭源服务。
